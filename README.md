# 🖥️ OnlineCompiler

A full-stack online code compiler built with the **MERN** stack (MongoDB, Express, React, Node.js), powered by **Vite** for the frontend and styled with **Tailwind CSS**.

---

## 🚀 Features

- 👨‍💻 Real-time code editor
- ⚙️ Compile and execute code on the backend
- 🌐 Supports multiple languages (e.g., C++, Python, Java)
- 🎨 Responsive UI with Tailwind CSS


---

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express
- MongoDB (via Mongoose)
